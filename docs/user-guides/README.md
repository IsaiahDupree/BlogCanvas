## 💡 Help System Integration

### In-App Help Tooltips

Throughout the BlogCanvas interface, you'll find help icons (?) that provide contextual information. These tooltips are powered by our centralized help system.

**For Developers:**
- Help content location: `/src/lib/help-content.tsx`
- Tooltip components: `/src/components/ui/tooltip.tsx` and `/src/components/ui/help-tooltip.tsx`
- To add tooltips to new features:
  ```tsx
  import { HelpTooltip } from "@/components/ui/help-tooltip"
  import { helpContent } from "@/lib/help-content"

  <div className="flex items-center gap-2">
    <label>SEO Score</label>
    <HelpTooltip content={helpContent.websites.seoScore} />
  </div>
  ```
